## 2. Findings that are expensive to rediscover

These cost real time to establish. Do not re-derive them; do re-verify any
that a protocol may have changed.

**A one-sided Meteora DLMM position is not a limit order.** Liquidity shares
claim whatever a bin holds, so USDC deposited below price fills into stock
and sells back on a bounce. No flag prevents it. The separate
`place_limit_order` primitive records fills with a monotonic `order_age`
counter and is genuinely one-way. Smart Accumulate depends on this
distinction.

**Meteora limit orders admit no operator.** `cancel_limit_order` and
`close_limit_order_if_empty` require `owner [SIGNER]`. A keeper can place an
order for an owner but can never settle or cancel one. Any automation design
that assumed otherwise is wrong.

**A DLMM LP operator cannot take principal.** The protocol routes withdrawn
principal to the owner whoever signs, and the SDK offers no operator path to
close a position. `enablePositionPermissionlessClaimFee` lets any keeper
claim fees to the fee owner with no power over capital — that is the right
shape for automation.

**Two SDK defects in `initializePositionByOperator`**: `positionWidth` is
accepted then ignored (a constant 70 is used, and width is a PDA seed), and
`ownerTokenX` is derived with the token *Y* program, which breaks on every
mixed SPL/Token-2022 pair. Derive it yourself.

**Kamino keeps no cost basis.** The collateral balance does not grow; the
exchange rate moves, and `getCollateralExchangeRate()` returns
collateral-per-liquidity, which *falls* as interest accrues. Realized yield
comes from a basis Henar records at deposit and re-baselines on harvest.
Kamino's MAIN market holds four USDC reserves, three of them dust, so the
real one is pinned by address: `D6q6wuQSrifJKZYpR1M8R4YawnLDtDsMmWM1NbBmgJ59`.

**Kamino's metrics endpoint emits scientific notation** for near-zero values
("5.601919084163853e-8"). A strict decimal regex rejected the whole MAIN
market. Rows are now parsed individually and a bad row is dropped, not fatal.
The older `src/lib/equities/earn/kamino.ts` still uses the strict regex; it
only works because the xStocks market happens to have clean values.

**Pyth's catalog `name` is the two symbol segments run together** ("NVDAXUSD"),
not the token symbol. A mapping rule comparing against it matched nothing on
real data. The rule now uses the token segment of `Crypto.<TOKEN>/USD` plus
an issuer keyword in the description.

**SPL extension id 16 is `ConfidentialTransferFeeConfig`** and the installed
`@solana/spl-token` does not name it. Until it was named explicitly, every
PreStocks mint read as carrying an unknown extension and was refused.

**Meteora DLMM liquidity for tokenized equities is thin.** Only NVDAx/USDC
(`F4inHs4RQARpASmvLpj45QjGLdkukeGQrtQ22pimVy2a`) clears both the depth and
turnover floors. Public equity routing remains Raydium CLMM and Orca.

   and the observe-mode findings have been watched for a while. Do not jump

## 5. Traps

- **`.env.local` is nearly empty.** Pull production config with
  `vercel env pull .env.local.pull --environment=production --yes`. Note
  `JUPITER_API_KEY` comes back **empty** from that pull, so local aggregator
  quotes fail; the router's own engine still quotes from chain.
- **The DLMM SDK fails under plain `tsx`** with an Anchor named-export error.
  The strategy adapter falls back to `createRequire`; any new script touching
  that SDK needs the same.
- **Meteora bin maths works in price per lamport**, and `getBinIdFromPrice`
  does not convert for you. Always go through `toPricePerLamport` first.
- **Do not fetch a strategy or Pyth panel only when the tab is visible.** The
  first read must always run; only polling pauses on a hidden tab. Both
  panels were fixed for this after they hung on "loading" in a background tab.
- **Registry invariants**: `pools.json` holds only USDC routes, routing legs
  through a qualified intermediate, and intermediates' own USDC pools, sorted
  by representation then TVL. Infrastructure pairs belong in
  `non-routable-pairs.json`. A discovery script that appends or writes infra
  rows will break `pool-registry-determinism` and `dbc-registry` tests.
